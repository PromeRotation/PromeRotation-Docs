# PromeRotation 对外 API

本目录按“外部开发者想完成什么”组织，而不是照搬宿主内部源码目录。当前只建立分类骨架；后续每个分类再补充稳定契约、类型索引、示例和版本说明。

## API 分类

| 目录 | 主要职责 | 典型使用者 |
| --- | --- | --- |
| `00-概览与约定-Overview-and-Conventions` | API 稳定性、命名、线程、所有权、错误和版本约定 | 全部开发者 |
| `01-插件开发-Plugin-Development` | 插件元数据、加载/卸载、初始化、异步停止和资源清理 | 插件 |
| `02-脚本开发-Scripting` | 脚本类型、执行上下文、生命周期、黑板和受控异步任务 | 脚本 |
| `03-ACR开发-ACR-Development` | 轮转元数据、生命周期、决策器、起手、QT、上下文和注册 | ACR |
| `04-时间轴-Timeline` | 条件、动作、节点、变量、职业扩展节点和运行时上下文 | 插件、脚本、ACR |
| `05-游戏数据与状态-Game-Data-and-State` | 本地玩家、对象查询、区域、战斗状态、状态效果、量谱和冷却 | 插件、脚本、ACR |
| `06-目标与队伍-Targeting-and-Party` | 目标解析与切换、选择模式、队伍查询和成员定位 | 插件、脚本、ACR |
| `07-动作与战斗控制-Action-and-Combat` | 技能/物品描述、可用性、队列、强制执行和战斗控制 | 插件、脚本、ACR |
| `08-绘制-Draw` | 绘制元素、样式、绑定、排期、句柄、移除和渲染器能力 | 插件、脚本、ACR |
| `09-空间与移动-Spatial-and-Movement` | 几何、安全区、朝向、移动请求、路径点和控制权释放 | 插件、脚本、ACR |
| `10-界面与热键-UI-and-Hotkeys` | 配置 UI、窗口、命令、快捷键、QT 面板和用户反馈 | 插件、ACR |
| `11-事件与网络-Events-and-Network` | 战斗/游戏事件、宿主 IPC、跨插件调用和兼容性协商 | 插件、脚本、ACR |
| `12-扩展与工具-Extensions-and-Utilities` | 日志诊断、配置存储以及无法归入核心能力域的扩展工具 | 插件、脚本、ACR |

## 分类规则

- API 文档描述稳定的外部契约；`public` 类型不自动等于受支持 API。
- 查询类能力尽量返回只读快照或接口；修改类能力通过明确的命令/服务发起。
- 事件订阅、绘制、热键、窗口、异步任务等资源必须有所有者，并能在卸载时统一清理。
- 高风险能力（强制技能、移动、朝向、目标切换等）必须说明线程、权限、抢占和释放语义。
- `12-扩展与工具` 不作为无边界的兜底目录；通用工具应优先归入它所服务的能力域。

探索依据和当前边界问题见 [CONTEXT.md](./CONTEXT.md)。
